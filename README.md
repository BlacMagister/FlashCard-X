# Japanese Flashcards App 🇯🇵

Aplikasi flashcard interaktif untuk belajar kosakata bahasa Jepang (Minna no Nihongo & Irodori), dibangun dengan React, TypeScript, Vite, Tailwind CSS, dan Framer Motion.

## 🚀 Fitur Utama
- **Flashcard Interaktif**: Animasi flip card untuk menebak arti/kosakata.
- **Dua Mode Belajar**: Pilih mode hafalan (Flashcard) atau mode tes (Challenge).
- **Pemilihan Bab Lengkap**: Terdapat bab dari Minna no Nihongo dan Irodori.
- **Custom Range Kosakata**: Bisa atur mulai dari nomor berapa sampai nomor berapa untuk diuji.
- **Pengaturan Lengkap**: Fitur acak urutan (shuffle), mulai ulang (restart), dan dukungan mode Gelap/Terang (Dark/Light mode).
- **Tampilan Responsif & Modern**: Desain UI yang indah dan adaptif untuk mobile maupun desktop.

## 🛠️ Teknologi yang Digunakan
- [React](https://reactjs.org/) (v19)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Motion (Framer Motion)](https://motion.dev/)
- [Lucide Icons](https://lucide.dev/)

## 📦 Menjalankan Secara Lokal (Local Development)

Pastikan kamu sudah menginstal [Node.js](https://nodejs.org/) di komputermu.

1. Clone repositori ini:
   ```bash
   git clone https://github.com/username/japanese-flashcards.git
   cd japanese-flashcards
   ```

2. Instal dependensi:
   ```bash
   npm install
   ```

3. Jalankan development server:
   ```bash
   npm run dev
   ```

4. Buka di browser: `http://localhost:3000`

## ⚡ Deployment Langsung ke Replit

Proyek ini sudah dilengkapi dengan konfigurasi `.replit` dan `replit.nix` sehingga kamu bisa langsung menjalankannya di Replit dengan 1 klik!

1. Salin URL repositori GitHub proyek ini.
2. Buka [Replit](https://replit.com/).
3. Pilih menu **"Create Repl"** -> Pilih **"Import from GitHub"**.
4. Paste URL repositori ke kolom yang tersedia dan klik **"Import from GitHub"**.
5. Tunggu proses instalasi otomatis. Replit akan menggunakan konfigurasi `.replit` untuk menjalankan `npm run dev` secara otomatis.
6. Aplikasi langsung live di Replit! 🚀
